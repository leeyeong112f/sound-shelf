# Sound Shelf

로컬 사운드 파일을 검색·분류·미리 듣고 DaVinci Resolve 타임라인으로 드래그하는 macOS 데스크톱 앱입니다.

## 실행

```bash
npm install
npm start
```

파형 분석과 선택 구간 WAV 생성에는 `ffmpeg`가 필요합니다.

```bash
brew install ffmpeg
```

## macOS 앱 빌드

```bash
npm run build:mac
```

완성된 앱은 `outputs` 폴더에 생성됩니다. 이 폴더와 개인 사운드 파일은 GitHub 저장소에 포함되지 않습니다.

## 현재 기능

- 마스터 폴더를 이동 가능한 Sound Shelf 볼트로 사용
- `.sound-shelf`에 볼트 UUID, 상대 경로, 태그·별점·메모·Key 결과와 폴더 순서 보관
- 볼트 열기·새 볼트 만들기·이동된 볼트 다시 연결·무결성 검사
- 파형·기술 정보·검색 인덱스는 Mac의 로컬 SQLite 캐시로 분리
- 영구 사운드 ID와 상대 경로 → 콘텐츠 해시 → 파일명+크기 순서의 재연결
- 파일 변경이 발생한 폴더만 우선 스캔하고 수동 재스캔 시 전체 검증
- 오디오 파일 또는 폴더 등록
- Finder에서 파일·폴더를 앱으로 드래그하여 등록
- 등록 폴더 재스캔 및 새 파일 감지
- 등록 폴더의 추가·복원·이동을 실시간 감시하고 자동 갱신
- 이름·카테고리·태그·메모 통합 검색
- 태그는 `#태그` 문법으로만 태그 전용 검색
- 실제 파일을 다른 폴더 또는 카테고리 폴더로 이동
- 라이브러리 항목만 삭제하거나 원본 파일을 macOS 휴지통으로 이동
- 카테고리 폴더와 태그를 각각 탐색·필터링
- Soundly 형태의 중첩 카테고리 폴더 트리와 펼치기·접기
- 상위 카테고리 선택 시 모든 하위 폴더 사운드 함께 표시
- 파일·카테고리 폴더 드래그 이동과 Finder식 우클릭 메뉴
- 우클릭으로 하위 폴더 생성, 파일 추가, 이름 변경, Finder 열기, 휴지통 삭제
- 즐겨찾기와 메타데이터 편집
- `⌘클릭` 추가 선택, `Shift클릭` 범위 선택, `⌘A` 전체 선택과 일괄 태그·이동·삭제
- 이름·길이·추가일·크기·별점 정렬과 별점·누락 상태 필터
- 0~5점 별점 편집
- 시작 시 자동 순환 백업, 수동 백업 내보내기·복원
- ID3/BWF 등 파일 내장 메타데이터 수집 및 검색
- SHA-256 콘텐츠 해시 기반 정확한 중복 파일 검사·정리
- 파일명과 크기 기반 누락 파일 자동 재연결 및 수동 재연결
- 검색 입력 디바운스와 고정 행 가상 스크롤
- 설정 화면에서 저장소·로드·가상 목록 성능 확인
- 검색·이동·태그·추가·삭제·재생 단축키 사용자 설정
- 오디오 미리 듣기
- 하단에 좌·우 채널을 합친 한 줄 파형 표시
- 파형 디스크 캐시 재사용 및 동시 분석 제한으로 재시작 부하 감소
- 미리듣기 음량 조절과 음소거 (설정값 자동 저장)
- 사운드 이름 오른쪽에 실제 오디오 파형 표시
- 파형 드래그로 구간 선택 및 선택 구간 미리 듣기
- 선택 구간만 임시 WAV로 만들어 Resolve에 드래그
- Finder에서 원본 위치 열기
- 기본 단축키: `⌘S` 검색, `⌘M` 카테고리 이동, `⌘T` 태그 편집, `⌘⌫` 원본 삭제, `⌘F` Fairlight로 보내기
- `⌘F`로 선택 사운드를 Resolve 타임헤드에 삽입 (파형 구간 선택 시 그 구간만 삽입)
- `⇧⌘N`으로 현재 보고 있는 카테고리 안에 새 하위 폴더 생성 (미선택 시 루트에 생성)
- 카테고리 폴더 `⇧클릭` 범위 선택, `⌘클릭` 개별 선택으로 다중 선택 (Esc로 해제)
- 다중 선택한 폴더를 한 번에 드래그하여 다른 폴더로 이동, 우클릭으로 일괄 휴지통
- 폴더를 "카테고리 폴더" 제목 영역이나 트리 빈 곳에 드롭하면 최상위로 이동
- 사운드 행 어디서든 드래그하여 DaVinci Resolve에 실제 파일 전달
- 사운드 이름을 더블클릭하여 Resolve의 현재 타임헤드·선택 오디오 트랙에 삽입

## DaVinci Resolve 자동 삽입 설정

`DaVinci Resolve > Preferences > System > General > External scripting using`을 `Local`로 설정하고 Resolve를 재시작합니다. 프로젝트와 타임라인을 연 뒤 Fairlight에서 삽입할 오디오 트랙을 선택하면 Sound Shelf의 사운드 이름 더블클릭으로 현재 타임헤드에 삽입됩니다. 이 기능은 Resolve Studio 스크립팅 API를 사용합니다.

태그·별점·메모·Key 결과와 폴더 순서는 볼트 안의 `.sound-shelf`에 저장됩니다. 절대 경로 대신 볼트 기준 상대 경로를 사용하므로 마스터 폴더를 옮겨도 같은 볼트로 다시 연결할 수 있습니다. 파형과 SQLite 검색 캐시는 Electron 사용자 데이터 폴더에 저장되며 삭제해도 자동으로 재생성됩니다. `sound-library.json`은 기존 버전 복구와 앱 설정 호환용으로 유지됩니다.
